# 热带海岛 · 设计简报

## 概念
一座被落日染成金色的热带海岛：白沙、棕榈、黑色礁石与红白灯塔，在真实海面和天空下随天气与时间连续变化。

## 需求清单
- Three.js 实时交互；鼠标环绕、平移、滚轮缩放。
- 多尺度动态海浪、反射、太阳闪光、白沫与地形驱动岸线泡沫。
- 沙滩、海岛地形、棕榈、岩石、灯塔、漂浮云层。
- 棕榈叶随风摆动；天空与光照随时间变化。
- 晴天、暴雨、夜晚三种天气；暴雨有风、雨线与闪电；夜晚有星空和旋转灯塔光束。
- 电影感 ACES 色调映射、大气透视、柔和阴影和层次构图。
- 全部场景、材质与纹理由代码生成；无外部图片、模型、视频。
- 首屏可见操作提示和天气按钮；目标 60 fps。

## 视觉决策
| 特征 | 实现 |
|---|---|
| 热带日落 | 17.65 小时起始，低角度暖色太阳与 ACES 高光压缩 |
| 白色沙滩 | 侵蚀岛地形自带干沙、湿沙与潮间带 |
| 动态海水 | 三层级联 FFT、风向谱、白冠、反射与海底深度泡沫 |
| 椰林 | 弯曲环纹树干、带小叶片的羽状叶，实例化渲染并独立风摆 |
| 海岸礁石 | 程序 fractured rock，多种尺度并沉入地形 |
| 灯塔 | 收分塔身、红色环带、窗框、挑台、栏杆、灯室与金属穹顶 |
| 暴雨 | 云量与风浪提升、雨线、闪电、较低环境亮度 |
| 夜晚 | 星空、冷色月光、暖色灯室与旋转体积光束 |

## 尺度与布局
- 岛地形约 1.4 km；主灯塔高约 22 m，塔基宽约 7 m。
- 灯塔位于程序选定的平坦近海位置；地形生成 14×14 m 水平基座。
- 主镜头位于灯塔海侧约 85 m、高 35 m，朝塔身和岛内取景。
- 棕榈分布在塔周与沙滩上方，礁石位于岸边，草只生长在地形草本遮罩内。

## 材质
- 灯塔灰泥 #D9D1C2，粗糙度 0.88；程序灰泥色斑与微法线。
- 红色涂层 #8E241C，粗糙度 0.55；深色金属 #242A2D，粗糙度 0.38。
- 树干 #66503A，粗糙度 0.95；叶片深绿/黄绿变化，粗糙度 0.76。
- 沙、岩、水由环境模块生成多尺度颜色、法线与粗糙度。

## 交互
- 左键环绕、右键平移、滚轮缩放；数字 1/2/3 切换天气；空格暂停时间；R 复位镜头。
- 顶部为标题与状态；底部为天气按钮、时间滑块、自动昼夜开关和操作提示。
- 编辑器暴露小时、云量、风速、浪高、棕榈风摆幅度。

## 性能预算
- 单一投影太阳；灯塔点光源和聚光灯不投影。
- 棕榈树干、叶片、椰子全部实例化；雨为单个 LineSegments。
- 海面约 18 万三角形，地形约 60 万；无后处理额外渲染通道。

## 路由
所有元素均在 Three.js 中生成，符合用户指定技术栈。地形、FFT 海洋、物理天空、礁石、草和海鸟使用本地环境代码模块；灯塔、椰林、雨与交互为本项目原创代码。无 Blender 路由、无下载资源。
