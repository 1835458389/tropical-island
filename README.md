# 热带海岛 · Three.js 实时交互场景

所有地形、海浪、天空、植被、建筑、材质和天气效果均由代码生成，不使用外部图片、3D 模型或预渲染视频。

## 运行

需要 Node.js 22.12 或更高版本。

```bash
npm install
npm run dev
```

构建独立运行版本：

```bash
npm run build
npm start
```

`dist/` 已包含独立构建；进入该目录后也可直接运行 `node server.mjs`，无需再次安装依赖。

## 操作

- 左键拖动：环绕镜头
- 右键拖动：平移镜头
- 滚轮：缩放
- `1` / `2` / `3`：晴天 / 暴雨 / 夜晚
- 空格：暂停或继续动画
- `R`：复位镜头
- 底部滑块：改变时间、太阳方向、天空颜色与海面反射
- “昼夜流转”：自动推进时间

## 源码入口

- `src/scene.js`：海岛、FFT 海洋、灯塔、实例化椰林、雨幕与天气状态
- `src/game.js`：OrbitControls 镜头、交互按钮、快捷键与 HUD
- `src/environment/`：物理天空、FFT 海洋、侵蚀地形、礁石、草地和海鸟
- `src/project.js`：项目与场景注册

进入“播放场景”即可使用完整交互；编辑模式可调整时间、云量、风速、浪高和椰叶风摆幅度。
